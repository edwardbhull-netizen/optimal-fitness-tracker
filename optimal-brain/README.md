# Optimal Brain: training knowledge

Coaching knowledge for building Optimal member programmes (built 11 October 2026).

Start here: `00_READ_ME_FIRST.md`

| File | Use |
|---|---|
| `Optimal_Brain_Training_Knowledge.txt` | Everything in one compact file (read me, coach principles, programming framework, exercise library). Best single file to give an AI. |
| `01_Coach_Principles.md` | How DeFranco, Cosgrove, Chek, Ben Patrick, Poliquin, Squat University, Gambetta and others think and programme. |
| `02_Programming_Framework.md` | The rulebook for building programmes (grades G1 to G4, loading, progressions, pain rules, special populations, templates, output format). |
| `03_Exercise_Library.md` | Full detail for all 1,069 exercises. |
| `Optimal_Exercise_Library.json` | Same library as structured data for the workout builder in the app. |
| `Optimal_Exercise_Library.csv` | Same library as a spreadsheet. |

Optimal's own rules (equipment, group session rules, BURN/STRONG/HYBRID, no jumping in groups) always take priority over these files.
